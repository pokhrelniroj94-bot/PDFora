# PDFora — Free Online PDF Tools & Utilities

**Try PDFora:** https://pd-fora.vercel.app/

PDFora is a free web-based toolkit for common PDF tasks and everyday utilities. Open a tool in your browser, add your input, and use the result without installing desktop software.

## What you can do

- **PDF workflows:** merge, split, compress, rotate, convert, reorder, extract, and organize PDF documents.
- **Calculators:** reading time, savings goals, percentage change, tips, dates, and other practical calculations.
- **Text and developer utilities:** format, convert, validate, and inspect common text and data formats.
- **Nepal-focused utilities:** selected date, finance, currency, and market tools.

The current directory includes **49 PDF tool routes and **120 catalog tools**, with 169 unified entries across the homepage and full tools directory. The available tools and supported file limits are documented on their individual pages.

## Privacy note

Some document workflows send files to the PDFora processing service to complete the requested operation. Review the [Privacy Policy](https://pd-fora.vercel.app/privacy) before uploading sensitive or confidential documents.

## Project

The website frontend is built with Next.js and React, with a Python service handling supported document-processing operations. This repository contains the PDFora application source. Feedback and bug reports are welcome through GitHub Issues.
