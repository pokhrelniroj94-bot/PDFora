# Translation coverage

Generated by `npm run i18n:coverage`.

The report separates source-language content from translated content. It does not treat a dictionary, route file, or locale code as proof of complete translation. Automated counts cannot certify native-speaker review.

**Method limits:** frontend page source-file counts are not runtime route counts. Dynamic route equivalents are reported as counts only. Shared UI coverage measures only the dedicated `shared-ui.ts` module, not every component, form, validation message, or error surface.
