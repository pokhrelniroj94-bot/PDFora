## Counting rule

The canonical tool count is derived from `legacy-tool-slugs.ts` plus `toolCatalog.ts`, excluding the `pdf-tools` collection entry. A route shell, catalog label, translated slug or shared dictionary does not count as a complete localized tool. OCR remains outside this 169-tool inventory.
